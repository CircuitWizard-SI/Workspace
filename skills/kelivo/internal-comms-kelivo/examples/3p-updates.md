# 3P 团队/项目周报

> 适配声明：基于 Anthropic internal-comms 技能中的 3P 更新指南调整；Apache-2.0 许可，见上级 `LICENSE.txt`。

适用于让少量背景的读者在 30–60 秒内了解一段周期的进展。默认覆盖过去一周的进展与问题，以及未来一周计划；以用户指定的周期为准。

格式固定为：

```text
[合适的 emoji] [团队或项目]（日期范围）
Progress: [1–3 句，已完成事项和可核实指标]
Plans: [1–3 句，未来优先事项与里程碑]
Problems: [1–3 句，阻碍、风险或“无新增问题”]
```

写作要求：
- 先确认团队/项目名称和日期范围；未提供时根据上下文拟用占位符，不编造。
- 区分已完成、正在进行和计划事项；只有有来源时才写指标。
- 内容简洁、客观、以事实为主。若信息不足，在末尾列出需补充的字段。

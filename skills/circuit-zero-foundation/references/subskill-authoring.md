# 子技能编写约定

每个章节子技能必须独立完成本章教学与解题，同时引用总技能的统一闭环，不重复大段通用渲染规则。

## 最低结构

- YAML frontmatter：唯一的 `name` 与完整 `description`。
- 本章定位与前置/后续章节。
- 知识树：按 PDF 小节组织。
- 核心概念：定义、直观解释、严格条件。
- 核心公式：只保留可用于解题的公式，并注明符号约定与适用范围。
- 标准算法：从读题、建模到校验的可执行步骤。
- 易错点：列出会导致答案错误的方向、条件、边界或单位问题。
- 典型题型：给出题型识别和方法选择，不伪造 PDF 中未复原的具体图形。
- 本章自测：至少覆盖概念、计算和综合迁移。

## 编写原则

- 以课程 PDF 为主，现有两个电路技能提供总框架、教学模式和考研训练规范。
- 删除口播、广告和重复表达，保留“为什么、怎么做、何时不能用”。
- 公式用正常 LaTeX 语义书写；最终聊天回答遵守总技能的 Minis 渲染规范。
- 不把针对特殊拓扑、特殊符号或特殊教材约定的结论泛化为所有电路。
- 不在子技能中假定任何院校考试范围；涉及 840 时先核验大纲。

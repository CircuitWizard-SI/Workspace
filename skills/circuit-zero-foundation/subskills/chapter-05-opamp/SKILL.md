# 第 5 章：运算放大器

## 模型与工作区

课程重点是理想运放。输入端电流为零，输入电阻趋于无穷，输出电阻为零；但输出端可以向外电路提供电流。在线性负反馈且未饱和时，两输入端等电位，即虚短，同时输入端虚断。无负反馈或输出超出电源限制时处于饱和/比较器状态，此时不能使用虚短。

## 解题流程

1. 判断反馈方向与工作区，不能先验套虚短。
2. 标出公共地和输入端电位，利用虚断令输入电流为零。
3. 用 KCL、KVL 或电位关系建立方程；反馈电阻中的电流由两端电压差确定。
4. 求出输出并检查是否超出饱和范围、反馈假设是否成立。

反相、同相、电压跟随、加法、差分等结构都归结为“运放约束 + 外部电阻网络 KCL/KVL”。推荐先画电位和中间变量，不把运放内部当普通节点写广义 KCL；省略的偏置电源意味着不能对“运放对地整体”简单列零电流。

## 易错点

虚短不是直接导线；虚断只表示输入端近似无电流，不表示输出端无电流；饱和区无虚短；反馈方向要看输出变化是否抑制输入差；理想运放输出电阻为零但输出电流不必为零。
